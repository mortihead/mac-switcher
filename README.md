# MacSwitcher

Маленькая замена Punto Switcher для macOS. Если текст набран не в той раскладке, выделите его и нажмите горячую клавишу:

- `ghbdtn? vbh!` → `привет, мир!`
- `руддщ` → `hello`

Направление перевода определяется само: каких букв больше, из той раскладки и переводим. Автоматического переключения нет и не планируется.

## Возможности

- Перевод выделенного текста QWERTY ⇄ ЙЦУКЕН по горячей клавише (по умолчанию `⌃⌥X`).
- Горячую клавишу можно сменить в настройках. Без модификаторов можно назначить § (клавиша слева от 1) и F1-F20.
- После перевода раскладка системы переключается на нужную (отключается в настройках).
- Таблица перевода строится из раскладок, которые включены у вас в системе, поэтому работают и «Русская», и «Русская – ПК».
- Запуск при входе в систему.
- Нативное приложение для Apple Silicon и Intel, macOS 13 или новее.

## Сборка и запуск

Нужны macOS 13+ и Xcode 15+ (или только Command Line Tools: `xcode-select --install`).

```bash
git clone https://github.com/mortihead/mac-switcher.git
cd mac-switcher
swift test                    # тесты логики перевода
./scripts/build-app.sh        # соберёт build/MacSwitcher.app
open build/MacSwitcher.app
```

В строке меню появится значок клавиатуры. Чтобы установить приложение насовсем, перетащите `build/MacSwitcher.app` в `/Applications`.

Готовую сборку можно скачать и без Xcode: на странице пул-реквеста или коммита откройте проверку **Build** → **Summary** → артефакт **MacSwitcher**. Приложение не подписано сертификатом Apple, поэтому после распаковки снимите карантин:

```bash
xattr -cr MacSwitcher.app
```

### Работа в Xcode

Отдельного `.xcodeproj` нет: Xcode умеет открывать Swift-пакет напрямую.

```bash
xed .        # или: open Package.swift
```

Слева появятся папки `Sources` и `Tests`. Схема `MacSwitcher` запускает приложение (⌘R), схема `MacSwitcher-Package` или ⌘U запускает тесты. При запуске из Xcode разрешение «Универсальный доступ» macOS запрашивает для самого Xcode. Для проверки «как у пользователя» удобнее собрать `.app` скриптом.

## Разрешение «Универсальный доступ»

Чтобы прочитать выделенный текст в чужом приложении, MacSwitcher делает то же, что и Punto Switcher: посылает `⌘C`, переводит текст из буфера обмена, посылает `⌘V` и возвращает прежнее содержимое буфера. Посылать нажатия клавиш другим программам macOS разрешает только с разрешением **Универсальный доступ** (Accessibility).

При первом запуске система сама предложит его выдать. Если пропустили: **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**, включите MacSwitcher. В настройках приложения есть кнопка, которая открывает этот раздел.

Важно при разработке: macOS привязывает разрешение к подписи приложения. Скрипт по умолчанию подписывает сборку ad-hoc, а такая подпись меняется при каждой пересборке. Если после пересборки перевод перестал работать, хотя переключатель включён, удалите MacSwitcher из списка кнопкой «−» и добавьте снова. Чтобы этого избежать, подпишите сборку постоянным сертификатом (бесплатный Apple ID в Xcode → Settings → Accounts его даёт):

```bash
security find-identity -v -p codesigning     # посмотреть свои сертификаты
SIGN_IDENTITY="Apple Development: ..." ./scripts/build-app.sh
```

## Как устроен проект

Если вы пишете на Java, вот примерные соответствия:

| Здесь | В мире Java |
|---|---|
| `Package.swift` | `pom.xml` / `build.gradle`: модули и зависимости |
| `swift build`, `swift test` | `mvn package`, `mvn test` |
| `Sources/<модуль>` | `src/main/java` отдельного модуля |
| `Tests/<модуль>Tests` (XCTest) | `src/test/java` (JUnit) |
| `Resources/Info.plist` | `MANIFEST.MF`: метаданные приложения |
| `.app` | папка-бандл, аналог «толстого» jar с лаунчером |

```
Package.swift
Sources/
  LayoutCore/                   чистая логика, без UI, покрыта тестами
    LayoutConverter.swift       таблица QWERTY ⇄ ЙЦУКЕН, определение направления, перевод
  MacSwitcher/                  приложение
    MacSwitcherApp.swift        точка входа (@main), меню в строке меню, окно настроек
    AppModel.swift              состояние и настройки (UserDefaults ≈ java.util.prefs)
    HotKey.swift                глобальная горячая клавиша (Carbon RegisterEventHotKey)
    Shortcut.swift              модель сочетания клавиш и его отображение (⌃⌥X)
    SelectionConverter.swift    ⌘C → перевод → ⌘V с сохранением буфера обмена
    KeyboardLayouts.swift       раскладки системы: таблица из них и переключение раскладки
    Accessibility.swift         проверка и запрос разрешения «Универсальный доступ»
    SettingsView.swift          окно настроек (SwiftUI) и запись сочетания клавиш
Tests/LayoutCoreTests/          тесты LayoutCore
Resources/Info.plist            метаданные бандла; LSUIElement прячет иконку из Dock
scripts/build-app.sh            сборка .app
.github/workflows/build.yml     CI на macOS: тесты, сборка, артефакт
```

Интерфейс написан на SwiftUI (декларативный UI, ближе всего к JavaFX с биндингами), системные вещи вроде горячих клавиш и имитации нажатий идут через AppKit, Carbon и CoreGraphics.
