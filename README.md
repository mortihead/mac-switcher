# MacSwitcher

Маленькая замена Punto Switcher для macOS. Если слово набрано не в той раскладке, сразу после набора нажмите горячую клавишу, и оно переведётся. Чтобы перевести несколько слов, выделите их и нажмите ту же клавишу.

- `ghbdtn` → `привет`
- `руддщ` → `hello`
- `Ghbdtn? vbh!` (выделено) → `Привет, мир!`

Направление перевода определяется само: каких букв больше, из той раскладки и переводим. Автоматического переключения нет и не планируется.

## Возможности

- Перевод QWERTY ⇄ ЙЦУКЕН по горячей клавише (по умолчанию `⌃⌥X`):
  - сразу после набора переводится последнее слово вместе с пробелами после него, повторное нажатие возвращает как было;
  - если после набора был клик мышью, стрелки, Return, Tab, Esc, команда с ⌘ или ⌃ или переход в другое приложение, переводится выделенный текст.
- Горячую клавишу можно сменить в настройках. Без модификаторов можно назначить § (клавиша слева от 1) и F1-F20.
- После перевода раскладка системы переключается на нужную (отключается в настройках).
- Таблица перевода строится из раскладок, включённых в системе, поэтому работают и "Русская", и "Русская - ПК".
- Запуск при входе в систему.
- Окно "О MacSwitcher" и раздел в настройках с версией и ссылкой на GitHub.
- Нативное приложение для Apple Silicon и Intel, macOS 13 или новее.

## Сборка и запуск

Нужны macOS 13+ и Xcode 15+ (или только Command Line Tools: `xcode-select --install`).

```bash
git clone https://github.com/mortihead/mac-switcher.git
cd mac-switcher
swift test                    # тесты логики перевода
./scripts/build-app.sh        # соберёт build/MacSwitcher.app
open build/MacSwitcher.app
```

В строке меню появится значок клавиатуры. Чтобы установить приложение насовсем, перетащите `build/MacSwitcher.app` в `/Applications`.

Готовую сборку можно скачать и без Xcode: на странице пул-реквеста или коммита откройте проверку **Build** → **Summary** → артефакт **MacSwitcher**. Приложение не подписано сертификатом Apple, поэтому после распаковки снимите карантин:

```bash
xattr -cr MacSwitcher.app
```

### Работа в Xcode

Отдельного `.xcodeproj` нет: Xcode открывает Swift-пакет напрямую.

```bash
xed .        # или: open Package.swift
```

Схема `MacSwitcher` запускает приложение (⌘R), ⌘U запускает тесты. При запуске из Xcode разрешение "Универсальный доступ" macOS запрашивает для самого Xcode, поэтому для проверки в реальных условиях удобнее собрать `.app` скриптом.

## Разрешение "Универсальный доступ"

Чтобы прочитать выделенный текст в чужом приложении, MacSwitcher делает то же, что и Punto Switcher: посылает `⌘C`, переводит текст из буфера обмена, посылает `⌘V` и возвращает прежнее содержимое буфера. Набранное слово он стирает нажатиями `⌫` и печатает перевод. Посылать нажатия клавиш другим программам и видеть набираемые символы macOS разрешает только с разрешением **Универсальный доступ** (Accessibility).

Набранный текст хранится только в памяти (последние 256 символов) и никуда не сохраняется и не отправляется. Пароли в защищённых полях macOS приложению не показывает.

При первом запуске система сама предложит выдать разрешение. Если пропустили: **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**, включите MacSwitcher. В настройках приложения есть кнопка, которая открывает этот раздел.

### Подпись и пересборка

macOS привязывает разрешение к подписи приложения. Подпись ad-hoc меняется при каждой пересборке, и после неё разрешение перестаёт действовать, хотя переключатель в списке включён. Чтобы этого не было, один раз создайте свой сертификат: **Связка ключей → Ассистент сертификации → Создать сертификат**, имя `MacSwitcher Dev`, тип "Подпись кода". Скрипт сборки найдёт его сам и подпишет им приложение. После этого удалите старую запись MacSwitcher из списка кнопкой "−" и выдайте разрешение ещё раз, дальше оно переживёт пересборки.

Другой сертификат можно указать явно:

```bash
security find-identity -p codesigning     # посмотреть свои сертификаты
SIGN_IDENTITY="Apple Development: ..." ./scripts/build-app.sh
```

## Как устроен проект

```
Package.swift                   описание пакета: модули и тесты
Sources/
  LayoutCore/                   чистая логика, без UI, покрыта тестами
    LayoutConverter.swift       таблица QWERTY ⇄ ЙЦУКЕН, определение направления, перевод
    TypingBuffer.swift          буфер набранного текста и выбор последнего слова
  MacSwitcher/                  приложение
    MacSwitcherApp.swift        точка входа (@main), меню в строке меню, окно настроек
    AppIcon.swift               значок в строке меню и большой значок, нарисованные кодом
    About.swift                 окно "О программе" и раздел настроек со ссылкой на GitHub
    AppModel.swift              состояние и настройки (UserDefaults)
    HotKey.swift                глобальная горячая клавиша (Carbon RegisterEventHotKey)
    Shortcut.swift              модель сочетания клавиш и его отображение (⌃⌥X)
    SelectionConverter.swift    выделение: ⌘C → перевод → ⌘V; набранное слово: ⌫ и печать перевода
    TypingMonitor.swift         слежение за набором (CGEventTap только на чтение)
    KeyboardLayouts.swift       раскладки системы: таблица из них и переключение раскладки
    Accessibility.swift         проверка и запрос разрешения "Универсальный доступ"
    SettingsView.swift          окно настроек (SwiftUI) и запись сочетания клавиш
Tests/LayoutCoreTests/          тесты LayoutCore (XCTest)
Resources/Info.plist            метаданные бандла; LSUIElement прячет иконку из Dock
scripts/build-app.sh            сборка и подпись .app
.github/workflows/build.yml     CI на macOS: тесты, сборка, артефакт
```

Интерфейс написан на SwiftUI, системные вещи вроде горячих клавиш и имитации нажатий идут через AppKit, Carbon и CoreGraphics.
